# Harisrujan

AI consultant and data scientist based in Helsinki, Finland. I work across
product, software engineering, and applied machine learning.

I build practical AI products and internal tools—from the first working
prototype to the APIs, evaluations, and infrastructure needed to make them
reliable in production.

## What I work on

- LLM products with useful, understandable workflows
- RAG and search systems for real business data
- Agent orchestration, tool use, and MCP integrations
- Backend APIs, data pipelines, and internal developer tools

## How I work

I start with the user’s actual problem, keep the first version small, and make
the system observable before making it clever. Good AI software should be
useful, explainable, and easy for the team that owns it to change.
